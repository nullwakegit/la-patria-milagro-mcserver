## 🕯️ En preparación

- **Hologramas con DecentHolograms.** Instalación y pruebas en curso. Queda por comprobar la visibilidad de los rótulos de estructuras en Java y Bedrock.
- **Modelos personalizados con Blockbench.** Planeados para una versión posterior. Quedan fuera de esta Alpha.

## 🏰 Cómo participar

Pide al equipo del servidor los datos de conexión de tu edición. Al entrar, revisa la bienvenida y busca al alcalde para probar **Un nuevo comienzo**. Si algo falla, sigue la [guía de pruebas](docs/guia-alpha.md) para preparar el reporte.

El repositorio contiene documentación del proyecto. El mapa **Aincardia Free Edition** se obtiene a través de su distribución original.
